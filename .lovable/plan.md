

# F.R.I.D.A.Y. Core Red — AI Command Interface

## Phase 1: The HUD (Visual Foundation)
- Full-screen immersive interface in deep crimson red and dark theme
- Animated floating rings/circles that pulse and glow (CSS/SVG animations)
- Central F.R.I.D.A.Y. orb that reacts when "speaking" or "thinking"
- Scanline effects, subtle grid overlays for sci-fi atmosphere
- Responsive design — works on desktop and mobile

## Phase 2: The Lock Screen (Iron Guard)
- PIN code entry screen with HUD-styled keypad
- Animated unlock sequence when correct PIN entered
- Session persistence so you stay logged in
- Lockout after failed attempts

## Phase 3: The Brain (AI Chat)
- F.R.I.D.A.Y. personality powered by Lovable AI (Gemini)
- Persona: Pepper Potts-inspired — witty, caring, professional, always calls you "Boss"
- Emotional intelligence in responses — adapts tone based on context
- Streaming text responses displayed in HUD-styled chat bubbles
- Conversation history maintained during session

## Phase 4: The Voice (ElevenLabs Integration)
- Text-to-speech: F.R.I.D.A.Y. speaks responses aloud with a female AI voice
- Speech-to-text: Talk to F.R.I.D.A.Y. using your microphone
- Voice toggle button — switch between text and voice modes
- Ring animations sync with audio playback

## Phase 5: Shopify Command Center
- Connect your Shopify store
- Product dashboard — view products, inventory, and orders
- Clean data display integrated into the HUD aesthetic

## Phase 6: Mobile Install (PWA)
- Progressive Web App setup so you can install F.R.I.D.A.Y. on your phone
- Full-screen app experience with no browser chrome
- Custom app icon in the F.R.I.D.A.Y. red theme
